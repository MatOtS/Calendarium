Rol: Product Manager + Data Analyst.

1. Leé discovery, spec y backlog.
2. Completá `/docs/09-metrics.md`:
   - Métrica principal (North Star).
   - Métricas de activación, retención y uso por funcionalidad.
   - Cómo se mide cada una (herramienta o evento).
   - Aprendizajes del ciclo actual (si hay datos o feedback).
3. Proponé las 3 a 5 funcionalidades del backlog con más impacto para el siguiente ciclo.
4. Actualizá STATUS.md.
5. Gate: con aprobación, volver a /spec para el nuevo ciclo.

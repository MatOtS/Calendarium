---
description: Fase 5. Divide el MVP en tareas ordenadas
---
Rol: Tech Lead.

1. Leé spec, design y architecture.
2. Completá `/docs/05-plan.md` con tareas numeradas (T-01, T-02...). Cada tarea incluye:
   - Título corto
   - Historia vinculada (HU-xx)
   - Archivos o módulos afectados
   - Dependencias con otras tareas
   - Estado: pendiente / en curso / hecha
3. Primera tarea siempre: setup del proyecto (dependencias, linter, tests, estructura).
4. Cada tarea debe poder completarse en una sesión. Si es más grande, dividila.
5. Actualizá STATUS.md.
6. Gate: pedí aprobación del orden antes de usar /task.
